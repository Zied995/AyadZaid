# 🌟 تطبيق إياد زيد التعليمي للأطفال | Ayad Zaid Kids App

تطبيق تعليمي تفاعلي للأطفال للهواتف الذكية (**iOS & Android**) باسم **Ayad Zaid** وبمشاركة ميكي ماوس الكارتوني، مصمم بأحدث تقنيات الويب وتطبيقات الهواتف الهجينة (PWA + Capacitor).

![Ayad Zaid](assets/images/ayad_thumbsup.jpg)

---

## 🎨 المميزات الرئيسية (Features)
- 🐭 **الترحيب وميكي ماوس المتحرك**: شخصية ميكي ماوس ترحب بالطفل إياد صوتياً وكتابياً مع كتابة متحركة بألوان الطيف.
- 🔢 **مملكة الرياضيات**: الأرقام من 1 إلى 10، ومن 10 إلى 20، ولعبة عد الأشياء الذكية، ولعبة تحدي الجمع السهل.
- 🔤 **حروف لغتي العربية**: 28 حرفاً، كل حرف مرتبط بـ **حيوان** أو **نبات/فاكهة** مع نطق صوتي فصيح.
- 📖 **روضة القرآن الكريم**: سورة الفاتحة (الحمد)، سورة الكوثر، وسورة الإخلاص مع تلاوة عذبة بصوت الشيخ مشاري العفاسي وتتبع الآية المقروءة.
- 🎈 **اللغة الإنجليزية وفرقعة الفقاعات**: الحروف (A-Z)، الأرقام (1-20)، ولعبة فرقعة الفقاعات الفيزيائية التفاعلية.
- 👨‍👩‍👧‍👦 **مراقبة الأهل ومؤقت الإيقاف الذاتي**: حماية الطفل بمؤقت يحدد وقت الشاشة مع شاشة نوم هادئة وقفل برمز الأهل (`4321`).

## 🚀 البناء التلقائي عبر GitHub Actions (Auto Build APK & IPA)
تم إعداد مسارات عمل سحابية تلقائية:
- **بناء الأندرويد (Android APK)**: يقع في `.github/workflows/build-apk.yml`.
- **بناء الآيفون (iOS IPA)**: يقع في `.github/workflows/build-ios.yml`.

بمجرد عمل Push إلى هذا المستودع، يقوم GitHub Actions ببناء حزم APK و IPA تلقائياً في تبويب **Actions > Artifacts**.

---

## 📱 التثبيت الفوري (PWA)
1. افتح التطبيق في المتصفح.
2. على **iPhone (Safari)**: اضغط Share 📤 ⬅️ "إضافة إلى الشاشة الرئيسية" (Add to Home Screen).
3. على **Android (Chrome)**: اضغط ⋮ ⬅️ "تثبيت التطبيق" (Install App).
